# Interview prep - frontend

## What to study

1. **JavaScript fundamentals**: closures, the event loop, promises and async/await.
2. **React**: rendering and reconciliation, hooks rules, state colocation, memoisation.
3. **Browser**: the critical rendering path, layout and paint, accessibility basics.
4. **Frontend system design**: design a news feed, an autocomplete, a photo gallery —
   data model, API, caching, pagination, performance budget.

## Practice

- Two timed coding problems a day, explained out loud.
- One system design mock a week; Maya offered to run one.
- Keep a list of stories for behavioural questions: conflict, failure, leadership.

## Logistics

Laptop charged, a quiet room, water, and the job description open in a second window.
