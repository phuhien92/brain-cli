# Onboarding checklist

For the first two weeks at a new job.

- [ ] Laptop, accounts, password manager, two-factor on everything.
- [ ] Read the team's docs and the last three months of planning notes.
- [ ] Meet each teammate for thirty minutes; ask what they wish they had known.
- [ ] Ship one small change in the first week.
- [ ] Set up the [[Weekly review template]] for the new job.
- [ ] Confirm health insurance enrollment and the start date of coverage.
